# Personal Expense Tracker 💰

A clean, lightweight, and interactive command-line **Personal Expense Tracker** built with Python.

## ✨ Current Features

* **Expense Management**: Add new expenses with custom amounts and categories.

* **History & Totals**: View a detailed list of all recorded expenses along with the calculated grand total.

* **Budget Tracking**: Input your monthly budget and instantly calculate your remaining balance.

* **Data Persistence**: Automatically saves and loads your financial records locally using a JSON file (`expenses.json`).

## 🚀 How to Run

Make sure you have **Python** installed on your system.

1. Clone the repository or download the source files.

2. Open your terminal or command prompt inside the project folder.

3. Run the application using:

   ```
   python main.py
   
   ```

4. Follow the on-screen menu prompts to manage your budget and expenses.
